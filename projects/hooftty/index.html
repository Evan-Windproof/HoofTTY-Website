About HoofTTY

HoofTTY explores how much personality a small operating system can convey through text, color, and a pixel mascot. It builds on the educational x86-64 monolithic kernel from Kernseed OS Phase 7 and keeps the shell at the center of the experience. It’s a fan-made project for learning kernel development, system programming, and low-level tools.

Getting Started

Install QEMU with x86-64 system emulation. In the folder where you saved hooftty.iso, run:

qemu-system-x86_64 -m 128M -vga std -nic none -cdrom hooftty.iso -boot d

Choose a mode in the Limine boot menu. The default is 800×600.

Documentation

User Guide

At the hoof> prompt, type a command and press Enter. The green underline marks the input position. Type friendship to list commands or friendship colors for help with colors. Use shutdown to power off the supported QEMU PC guest.

Choose 640×480, 800×600, 1024×768, or 1280×720 at boot. The terminal uses fixed-size ASCII bitmap glyphs and supports 16 foreground colors.

Developer Guide

Use Linux or WSL with GCC, GNU binutils, GNU Make, Python 3, Git, xorriso, and QEMU. The first build fetches a pinned Limine revision and checks its hashes.

git clone https://github.com/Evan-Windproof/HoofTTY.git
cd HoofTTY
git checkout beta0.4.0
make iso
make run

The build writes build/kernseed.iso. Run make test-host for host unit tests and make check for ELF checks.

Command Reference

Commands are case-sensitive. The list below follows the Beta 0.4.0 command registry.

CommandPurpose
aboutShow system information.
appsList embedded applications.
colorsDisplay the 16 foreground colors.
echo [text ...]Print up to seven parsed arguments.
friendship [command]List commands or show help for one command.
meminfoShow physical-memory statistics.
partyPrint a Pinkie Pie–themed message.
rainboomClear the terminal.
rebootRequest a PC reset via the i8042 controller.
run nameRun an embedded Ring 3 application, such as run hello.
shutdownPower off a supported QEMU PC guest.
tasksShow kernel task states and runtime counters.
uptimeShow elapsed PIT ticks and estimated seconds.
yayPrint a Fluttershy-inspired cheer.
